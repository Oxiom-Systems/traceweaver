A meta element may carry only UTF-8 charset declaration or viewport metadata and never http-equiv; href may occur only on a. A versioned successor schema may change this closed set only by review.

Controlled migration phases

M0

Candidate contract

Review needs, requirements, schema vocabulary, hashes, relationships, and V&V. No runtime changes.

M1

Generated bridge

Generate read-only HTML from Markdown authority. Measure navigation, reviewability, parity, drift, and overhead.

M2

Verified projection reader, explicit Markdown/YAML owners

Consumers may navigate HTML only after the versioned three-source closure registry, every source hash and locator, owned-field extraction, copied-fact agreement, completeness, and parity checks pass. Requirements Markdown owns needs and normative requirements; traceability Markdown owns trace/evidence-link/gap/tombstone state; the Intent Contract owns baseline selection, mode, active gate, held claims, and workflow-policy pointers. Every authority decision and repair resolves to that named owner. Missing, stale, incomplete, or conflicting input rejects the projection; it is never merged or used as fallback authority.

M3

Cutover rehearsal

Freeze and independently reproduce the accepted closed observable consumer boundary and versioned authority-consumer census, reconcile every static, dynamic, installed-root, external, and out-of-tree discovery candidate one-to-one, observe deny-by-default authority resolution in every supported runtime configuration, then run full compatibility, normalized-model, canonical member/control-plane/baseline hash, link, atomic-pair rollback, Graphify-absent, and per-cell stakeholder review suites. The boundary and census are not yet created; runtime enforcement and this phase remain held.

M4

Owner-approved cutover

Accept one matched authority_baseline_manifest_v2/intent_control_plane_v1 pair, switch every included census writer atomically, regenerate derived views from that pair, and freeze the prior Markdown authority as immutable linked history. Any member, control-plane, writer, or pair-consistency failure rolls the whole set back to the last accepted matched pair.

M5

Markdown import-only retirement

Reject legacy Markdown for live reads, writes, freshness fallback, review gates, bootstrap, or dual authority. Retain it only for an auditable one-time import, historical links, or an explicit owner-approved rollback; delete no historical source until retention and link-closure rules pass.

  • No HTML parser, canonicalizer, generator, writer, bootstrapper, link checker, hook, CI check, or routing adapter implementation.
  • No tw-graph or Graphify mutation and no graph publication.
  • No refresh of derived traceability views or intent-contract.current.yml.
  • No baseline manifest, canonical hash, migration, usability-validation, or cutover implementation or acceptance.
