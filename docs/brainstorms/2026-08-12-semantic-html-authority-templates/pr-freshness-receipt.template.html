Changed-scope digest

Deterministic tree-difference rule: build raw recursive path maps from the exact base and reviewed Git trees with rename/copy detection disabled. Only regular-blob A, M, and D entries exist: reviewed-only is A with empty old path and absent old content; base-only is D with empty new path and absent new content; same-path changed tree-entry identity is M with equal non-empty paths and both content digests. Moves serialize as D plus A; copies as A; no rename record, heuristic pairing, or A/D coalescing is permitted. Any changed non-regular entry fails as unsupported_changed_entry_type. Every changed path byte sequence must decode as strict UTF-8 before serialization or the receipt becomes incomplete with changed_scope_path_not_utf8 and emits no digest. Apply no replacement, escaping, Unicode normalization, or locale collation; sort by unsigned UTF-8 bytes of (new_path if non-empty else old_path, change_kind, old_path).
